## Major Rules And Lessons

- [created: 2976c4f] Generic host stays independent of TE2/sample/renderer policy.
  Native immutable descriptors select entries/methods/events; renderer input
  cannot select arbitrary paths/modules/argv or authorize itself.
- [created: 2976c4f] Exact current document/generation gates requests/replies/events;
  loopback origin alone grants no privilege. Shared UID is a trust domain, not
  isolation from another process with that UID.
- [created: 2976c4f] Node initializes once per process. Retain declaration/failure;
  Service recreation or Activity detach cannot close/reinitialize the engine.
  Child/consumer/channel disposal follows its own declared ownership.
- [created: 2976c4f] Bound framing/queues/output/deadlines. Replies, native-effect
  ACKs and events must progress while commands wait; ACKs cannot use the serial
  consumer command lane.
- [created: 2976c4f] No uncertain mutation replay, silent unsupported no-ops,
  global require/version spoofing or implicit engine restart. Declare unsupported
  subsets/reasons; callbacks remain at their actual owner.
- [created: 2976c4f] Engine/channel/renderer/child lifetime and readiness differ.
  Browser loading callbacks aren't exact-document readiness; register native
  callbacks before loading Cefrium Surface documents.
- [created: 2976c4f] Source resource inventories aren't APK contents; verify assembled
  resources/entrypoints and R8/JNI/menu/lifetime behavior. Don't commit local SDK/
  keystore/heap environment or conflate sample signing with shared-UID consumers.
- [created: 2976c4f] Evolve APIs additively and test existing consumers; coordinated
  native/consumer changes update both. Smoke success isn't full compatibility,
  crash recovery/background survival or redistribution clearance.
- [created: 2976c4f] Android `run-as` signal probes can return EPERM for a live
  shared-UID process. Use authenticated state and exact process/cleanup evidence;
  signal-probe failure isn't proof of exit. Keep the incident in the feature tracker.
- [created: 2976c4f] Every agent maintains the owning feature tracker. Tests,
  device/user acceptance prose and pending gates belong there. Memory promotes
  only generalized lessons useful outside the current task, with a source pointer.
